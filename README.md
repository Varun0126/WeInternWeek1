The Student Management System is a Java-based desktop application that allows users to manage student records efficiently using a graphical interface.

It supports basic CRUD operations (Create, Read, Update, Delete) and provides an interactive Swing GUI for easy data handling instead of a console-based system.

This project demonstrates:

Object-Oriented Programming (OOP)

Java Collections Framework

GUI Development using Swing

Event Handling

MVC
